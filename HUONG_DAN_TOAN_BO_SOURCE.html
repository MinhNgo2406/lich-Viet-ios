1. Ứng dụng gồm những gì?

Đây là ứng dụng iPhone viết bằng Swift và giao diện SwiftUI. Nó hiển thị lưới lịch tháng dương, số ngày âm tương ứng, một số ngày lễ Việt Nam, ghi chú cục bộ và các sự kiện Google Calendar nếu người dùng đã đăng nhập.

Giao diệnContentView.swift dựng lịch tháng, ngày đang chọn, ghi chú và form sửa ghi chú.
Dữ liệu ngàyCalendarData.swift chuyển đổi âm lịch theo múi giờ Việt Nam và tra tên ngày lễ.
Lưu & nhắcCalendarStore lưu ghi chú trên máy; LocalReminderCenter đăng ký thông báo iOS.
GoogleGoogleCalendarService.swift đăng nhập, gọi API đọc lịch chính và chuyển dữ liệu sự kiện.

Điều quan trọng về tên

Tên hiện trên iPhone được đặt là Lịch Việt. Tên project, scheme và target bên trong Xcode vẫn là Calendar; đó là tên kỹ thuật để build, không phải nhãn app ngoài màn hình chính.

2. Cách mở và chạy app

  1. Mở Xcode, chọn File → Open và mở Calendar.xcodeproj trong thư mục project.
  2. Đợi Xcode tải Swift Package của GoogleSignIn lần đầu. Máy cần internet để tải package.
  3. Trên thanh công cụ, chọn scheme Calendar và chọn iPhone Simulator hoặc iPhone thật đã cắm vào Mac.
  4. Nếu chạy iPhone thật: chọn target Calendar → Signing & Capabilities → bật Automatically manage signing và chọn Team Apple ID của bạn.
  5. Nhấn nút ▶️ Run hoặc bấm ⌘R. Xcode build app rồi cài/chạy lên thiết bị đã chọn.
# Nếu muốn mở project từ Terminal: open Calendar.xcodeproj

Project đặt phiên bản iOS tối thiểu là iOS 16. Thiết bị thật phải chạy iOS tương thích và Xcode phải nhận ra thiết bị. Khi cắm iPhone lần đầu, mở khóa máy, chọn Trust This Computer nếu iPhone hỏi.

Google Sign-In chưa sẵn sàng trong cấu hình hiện tại. Các biến GOOGLE_IOS_CLIENT_ID và GOOGLE_REVERSED_CLIENT_ID vẫn là giá trị mẫu YOUR_.... Vì thế nút đăng nhập đang bị khóa và app sẽ yêu cầu cấu hình OAuth. Lịch, ngày âm, ghi chú và thông báo cục bộ vẫn là các phần riêng.

Khi mở ứng dụng

MyApp tạo cửa sổ chứa ContentView. Khi view hiện lên, restorePreviousSignIn() thử phục hồi phiên Google đã lưu (nếu OAuth đã cấu hình). SwiftUI đọc các thuộc tính trạng thái và vẽ giao diện tương ứng.

Khi đổi tháng hoặc ngày

Nút mũi tên đổi displayedMonth, còn chạm một ô đổi selectedDate. Mỗi ô lịch tính ngày dương, ngày âm, lễ, ghi chú và sự kiện để vẽ các dấu màu. Khi đổi tháng, app yêu cầu dịch vụ Google đồng bộ khoảng ngày cần hiển thị.

Khi lưu một ghi chú

Form tạo CalendarNote có mã UUID, khóa ngày dạng yyyy-MM-dd, tiêu đề, chi tiết và thời điểm nhắc tùy chọn. Store thay ghi chú cũ cùng ID hoặc thêm ghi chú mới, mã hóa danh sách thành JSON trong UserDefaults, rồi yêu cầu iOS đặt thông báo nếu có giờ nhắc trong tương lai.

Khi tải sự kiện Google

Dịch vụ làm mới access token, gửi HTTP GET tới endpoint /calendar/v3/calendars/primary/events với thời điểm đầu/cuối và token Bearer. Nó đọc trang kết quả tiếp theo nếu API cung cấp nextPageToken, bỏ sự kiện đã hủy hoặc không đủ dữ liệu, rồi ánh xạ sự kiện vào một hay nhiều ngày dương.

5. Những cú pháp SwiftUI thường gặp

struct ContentView: ViewĐịnh nghĩa một thành phần giao diện. var body mô tả cây view SwiftUI cần dựng.
@StateTrạng thái riêng của một view, ví dụ ngày đang chọn hay sheet có đang mở hay không. Đổi giá trị sẽ khiến giao diện vẽ lại.
@StateObjectTạo và giữ một model ObservableObject tồn tại cùng view, ở đây là store ghi chú và dịch vụ Google.
@PublishedKhi giá trị trong model đổi, các view đang quan sát model nhận tín hiệu để cập nhật giao diện.
@MainActorBuộc các thao tác trạng thái giao diện chạy trên luồng chính an toàn cho UI.
some ViewKiểu trả về view cụ thể nhưng được SwiftUI che giấu dưới một kiểu tổng hợp.
.sheetTrình bày một màn hình dạng sheet, ví dụ form ghi chú hoặc cài đặt Google.
Task { await ... }Chạy việc bất đồng bộ như tải API hoặc xin quyền notification mà không chặn giao diện.

Ví dụ: mô hình ghi chú

struct CalendarNote: Identifiable, Codable, Equatable {
    var id: UUID = UUID()
    var dateKey: String
    var title: String
    var details: String
    var reminder: Date?
}

Identifiable giúp SwiftUI phân biệt từng dòng; Codable cho phép biến thành JSON để lưu; Equatable cho phép so sánh. Dấu hỏi sau Date? nghĩa là có thể không đặt nhắc.

Ví dụ: dữ liệu ngày âm

let lunar = VietnameseLunarCalendar.date(from: date)
Text(lunar.map { "\($0.day)" } ?? "—")

Hàm trả về ngày âm hoặc nil nếu ngoài phạm vi hỗ trợ. map tạo chuỗi khi có kết quả; ?? dùng dấu gạch khi không có.

6. Hành vi và giới hạn cần nhớ

  • Phạm vi âm lịch: 1900–2100; thuật toán dùng múi giờ UTC+7 để phù hợp ngày dân sự Việt Nam.
  • Ngày lễ: danh sách đang được khai báo trực tiếp trong code. Đây không phải lịch ngày nghỉ hằng năm đầy đủ; lịch nghỉ bù/nghỉ lễ theo quyết định từng năm chưa được tải từ máy chủ.
  • Ghi chú: lưu cục bộ trong UserDefaults trên iPhone này; hiện không đồng bộ ghi chú giữa các thiết bị/iCloud.
  • Nhắc việc: notification được lên lịch cục bộ trên máy; iOS cần người dùng cấp quyền. Nếu giờ nhắc đã qua, code không lên lịch thông báo.
  • Google Calendar: chỉ đọc sự kiện trong lịch chính, không tạo/sửa/xóa sự kiện. OAuth vẫn là placeholder, nên đăng nhập chưa hoạt động cho tới khi cấu hình Google Cloud và URL scheme thật.
  • Khoảng đồng bộ: lưới tháng hiển thị sáu tuần; app yêu cầu các sự kiện trong khoảng đó và gắn chấm vào ngày tương ứng.
Nếu bạn đổi Bundle ID trong Xcode thì OAuth client iOS và cấu hình redirect cũng phải khớp Bundle ID mới. Không đưa client secret, private key, file .p12 hoặc provisioning profile lên GitHub.

import SwiftUI
import Combine
import UserNotifications

@MainActor
final class CalendarStore: ObservableObject {
    @Published private(set) var notes: [CalendarNote] = []
    private let storageKey = "calendar.notes.v1"

    init() {
        if let data = UserDefaults.standard.data(forKey: storageKey),
           let saved = try? JSONDecoder().decode([CalendarNote].self, from: data) {
            notes = saved
        }
    }

    func notes(on date: Date) -> [CalendarNote] {
        notes.filter { $0.dateKey == CalendarDateKey.string(from: date) }
            .sorted { ($0.reminder ?? .distantFuture) < ($1.reminder ?? .distantFuture) }
    }

    func save(_ note: CalendarNote) {
        if let index = notes.firstIndex(where: { $0.id == note.id }) {
            notes[index] = note
        } else {
            notes.append(note)
        }
        persist()
        Task { await LocalReminderCenter.shared.schedule(note) }
    }

    func delete(_ note: CalendarNote) {
        notes.removeAll { $0.id == note.id }
        persist()
        LocalReminderCenter.shared.cancel(note)
    }

    private func persist() {
        guard let data = try? JSONEncoder().encode(notes) else { return }
        UserDefaults.standard.set(data, forKey: storageKey)
    }
}

@MainActor
final class LocalReminderCenter {
    static let shared = LocalReminderCenter()
    private let center = UNUserNotificationCenter.current()

    func schedule(_ note: CalendarNote) async {
        let identifier = note.id.uuidString
        center.removePendingNotificationRequests(withIdentifiers: [identifier])
        guard let reminder = note.reminder, reminder > Date() else { return }
        do {
            let allowed = try await center.requestAuthorization(options: [.alert, .sound, .badge])
            guard allowed else { return }
            let content = UNMutableNotificationContent()
            content.title = note.title.isEmpty ? "Nhắc việc" : note.title
            content.body = note.details.isEmpty ? "Bạn có một việc cần nhớ hôm nay." : note.details
            content.sound = .default
            let components = Calendar.current.dateComponents([.year, .month, .day, .hour, .minute], from: reminder)
            let trigger = UNCalendarNotificationTrigger(dateMatching: components, repeats: false)
            try await center.add(UNNotificationRequest(identifier: identifier, content: content, trigger: trigger))
        } catch {
            print("Không thể lên lịch thông báo: \(error.localizedDescription)")
        }
    }

    func cancel(_ note: CalendarNote) {
        center.removePendingNotificationRequests(withIdentifiers: [note.id.uuidString])
    }
}

struct LunarDate: Equatable {
    let day: Int
    let month: Int
    let year: Int
    let isLeapMonth: Bool
}

/// Vietnamese lunisolar calendar using the UTC+7 civil-time convention.
/// Based on the new-moon / solar-longitude method commonly known as Hồ Ngọc Đức's algorithm.
enum VietnameseLunarCalendar {
    private static let timeZone = 7.0
    private static let epoch = 2415021.076998695

    static func date(from solarDate: Date) -> LunarDate? {
        var vietnam = Calendar(identifier: .gregorian)
        vietnam.timeZone = TimeZone(secondsFromGMT: 7 * 3600)!
        let c = vietnam.dateComponents([.day, .month, .year], from: solarDate)
        guard let day = c.day, let month = c.month, let year = c.year,
              (1900...2100).contains(year) else { return nil }

        let dayNumber = julianDay(day: day, month: month, year: year)
        let k = Int(floor((Double(dayNumber) - epoch) / 29.530588853))
        var monthStart = newMoonDay(k + 1)
        if monthStart > dayNumber { monthStart = newMoonDay(k) }

        var a11 = lunarMonth11(year)
        var b11 = a11
        let lunarYear: Int
        if a11 >= monthStart {
            lunarYear = year
            a11 = lunarMonth11(year - 1)
        } else {
            lunarYear = year + 1
            b11 = lunarMonth11(year + 1)
        }

        let lunarDay = dayNumber - monthStart + 1
        let diff = Int(floor(Double(monthStart - a11) / 29.0))
        var lunarMonth = diff + 11
        var leap = false
        if b11 - a11 > 365 {
            let leapOffset = leapMonthOffset(a11)
            if diff >= leapOffset {
                lunarMonth = diff + 10
                leap = diff == leapOffset
            }
        }
        if lunarMonth > 12 { lunarMonth -= 12 }
        var adjustedYear = lunarYear
        if lunarMonth >= 11 && diff < 4 { adjustedYear -= 1 }
        return LunarDate(day: lunarDay, month: lunarMonth, year: adjustedYear, isLeapMonth: leap)
    }

    private static func julianDay(day: Int, month: Int, year: Int) -> Int {
        let a = (14 - month) / 12
        let y = year + 4800 - a
        let m = month + 12 * a - 3
        var jd = day + (153 * m + 2) / 5 + 365 * y + y / 4 - y / 100 + y / 400 - 32045
        if jd < 2299161 { jd = day + (153 * m + 2) / 5 + 365 * y + y / 4 - 32083 }
        return jd
    }

    private static func newMoonDay(_ k: Int) -> Int {
        Int(floor(newMoon(k) + 0.5 + timeZone / 24.0))
    }

    private static func newMoon(_ k: Int) -> Double {
        let t = Double(k) / 1236.85
        let t2 = t * t
        let t3 = t2 * t
        let dr = Double.pi / 180
        var jd = 2415020.75933 + 29.53058868 * Double(k) + 0.0001178 * t2 - 0.000000155 * t3
        jd += 0.00033 * sin((166.56 + 132.87 * t - 0.009173 * t2) * dr)
        let m = 359.2242 + 29.10535608 * Double(k) - 0.0000333 * t2 - 0.00000347 * t3
        let mp = 306.0253 + 385.81691806 * Double(k) + 0.0107306 * t2 + 0.00001236 * t3
        let f = 21.2964 + 390.67050646 * Double(k) - 0.0016528 * t2 - 0.00000239 * t3
        var correction = (0.1734 - 0.000393 * t) * sin(m * dr) + 0.0021 * sin(2 * m * dr)
        correction -= 0.4068 * sin(mp * dr) + 0.0161 * sin(2 * mp * dr)
        correction -= 0.0004 * sin(3 * mp * dr)
        correction += 0.0104 * sin(2 * f * dr) - 0.0051 * sin((m + mp) * dr)
        correction -= 0.0074 * sin((m - mp) * dr) + 0.0004 * sin((2 * f + m) * dr)
        correction -= 0.0004 * sin((2 * f - m) * dr) - 0.0006 * sin((2 * f + mp) * dr)
        correction += 0.0010 * sin((2 * f - mp) * dr) + 0.0005 * sin((2 * mp + m) * dr)
        let deltaT: Double
        if t < -11 {
            deltaT = 0.001 + 0.000839 * t + 0.0002261 * t2 - 0.00000845 * t3 - 0.000000081 * t2 * t2
        } else {
            deltaT = -0.000278 + 0.000265 * t + 0.000262 * t2
        }
        jd += correction - deltaT
        return jd
    }

    private static func sunLongitude(_ dayNumber: Int) -> Double {
        let t = (Double(dayNumber) - 0.5 - timeZone / 24.0 - 2451545.0) / 36525.0
        let t2 = t * t
        let dr = Double.pi / 180
        let m = 357.52910 + 35999.05030 * t - 0.0001559 * t2 - 0.00000048 * t * t2
        let l0 = 280.46645 + 36000.76983 * t + 0.0003032 * t2
        var deltaL = (1.914600 - 0.004817 * t - 0.000014 * t2) * sin(dr * m)
        deltaL += (0.019993 - 0.000101 * t) * sin(2 * dr * m) + 0.000290 * sin(3 * dr * m)
        var longitude = (l0 + deltaL) * dr
        longitude -= 2 * Double.pi * floor(longitude / (2 * Double.pi))
        return longitude
    }

    private static func lunarMonth11(_ year: Int) -> Int {
        let off = julianDay(day: 31, month: 12, year: year) - 2415021
        let k = Int(floor(Double(off) / 29.530588853))
        var nm = newMoonDay(k)
        if Int(floor(sunLongitude(nm) / Double.pi * 6)) >= 9 { nm = newMoonDay(k - 1) }
        return nm
    }

    private static func leapMonthOffset(_ a11: Int) -> Int {
        let k = Int(floor(0.5 + Double(a11 - 2415021) / 29.530588853))
        var i = 1
        var last = Int(floor(sunLongitude(newMoonDay(k + i)) / Double.pi * 6))
        var arc = last
        repeat {
            last = arc
            i += 1
            arc = Int(floor(sunLongitude(newMoonDay(k + i)) / Double.pi * 6))
        } while arc != last && i < 14
        return i - 1
    }
}

            self.isSignedIn = user != nil
            if user != nil {
                Task { await self.sync(for: self.lastRequestedMonth) }
            }
        }
    }

    func signIn(presenting controller: UIViewController, month: Date) async {
        guard Self.isConfigured else {
            errorMessage = "Chưa cấu hình Google OAuth. Hãy thay Client ID và URL scheme trong GoogleOAuthInfo.plist / Build Settings bằng thông tin từ Google Cloud."
            return
        }
        isLoading = true
        errorMessage = nil
        defer { isLoading = false }
        do {
            let result = try await GIDSignIn.sharedInstance.signIn(
                withPresenting: controller,
                hint: nil,
                additionalScopes: [Self.readOnlyScope]
            )
            currentUser = result.user
            accountEmail = result.user.profile?.email
            isSignedIn = true
            await sync(for: month)
        } catch {
            errorMessage = "Không đăng nhập được Google: \(error.localizedDescription)"
        }
    }

    func signOut() {
        GIDSignIn.sharedInstance.signOut()
        currentUser = nil
        accountEmail = nil
        isSignedIn = false
        events = []
        lastSyncedAt = nil
        errorMessage = nil
    }

    func sync(for month: Date) async {
        lastRequestedMonth = month
        guard Self.isConfigured, let currentUser else { return }
        isLoading = true
        errorMessage = nil
        defer { isLoading = false }

        do {
            let refreshedUser = try await currentUser.refreshTokensIfNeeded()
            self.currentUser = refreshedUser
            let token = refreshedUser.accessToken.tokenString
            let range = visibleRange(for: month)
            events = try await fetchEvents(accessToken: token, from: range.start, to: range.end)
            lastSyncedAt = Date()
        } catch {
            errorMessage = "Không đồng bộ được Google Calendar: \(error.localizedDescription)"
        }
    }

    func events(on date: Date) -> [GoogleCalendarEvent] {
        events.filter { $0.occurs(on: date) }
            .sorted { ($0.start ?? .distantFuture) < ($1.start ?? .distantFuture) }
    }

    private func visibleRange(for month: Date) -> (start: Date, end: Date) {
        let calendar = CalendarDateKey.calendar
        let firstOfMonth = calendar.date(from: calendar.dateComponents([.year, .month], from: month)) ?? month
        let weekday = calendar.component(.weekday, from: firstOfMonth)
        let mondayOffset = (weekday + 5) % 7
        let start = calendar.date(byAdding: .day, value: -mondayOffset, to: firstOfMonth) ?? firstOfMonth
        let end = calendar.date(byAdding: .day, value: 42, to: start) ?? firstOfMonth
        return (start, end)
    }

    private func fetchEvents(accessToken: String, from start: Date, to end: Date) async throws -> [GoogleCalendarEvent] {
        var allEvents: [GoogleCalendarEvent] = []
        var pageToken: String?

        repeat {
            var components = URLComponents(string: "https://www.googleapis.com/calendar/v3/calendars/primary/events")!
            var query: [URLQueryItem] = [
                URLQueryItem(name: "timeMin", value: Self.apiDateFormatter.string(from: start)),
                URLQueryItem(name: "timeMax", value: Self.apiDateFormatter.string(from: end)),
                URLQueryItem(name: "singleEvents", value: "true"),
                URLQueryItem(name: "orderBy", value: "startTime"),
                URLQueryItem(name: "maxResults", value: "2500"),
            ]
            if let pageToken { query.append(URLQueryItem(name: "pageToken", value: pageToken)) }
            components.queryItems = query
            guard let url = components.url else { throw GoogleCalendarError.invalidURL }

            var request = URLRequest(url: url)
            request.setValue("Bearer \(accessToken)", forHTTPHeaderField: "Authorization")
            request.setValue("application/json", forHTTPHeaderField: "Accept")
            let (data, response) = try await URLSession.shared.data(for: request)
            guard let http = response as? HTTPURLResponse else { throw GoogleCalendarError.invalidResponse }
            guard (200..<300).contains(http.statusCode) else {
                let detail = String(data: data, encoding: .utf8) ?? ""
                throw GoogleCalendarError.api(status: http.statusCode, detail: detail)
            }
            let page = try JSONDecoder().decode(GoogleEventsPage.self, from: data)
            allEvents.append(contentsOf: page.items.compactMap(GoogleCalendarEvent.init(payload:)))
            pageToken = page.nextPageToken
        } while pageToken != nil

        return allEvents.sorted { ($0.start ?? .distantFuture) < ($1.start ?? .distantFuture) }
    }

    private static let apiDateFormatter: DateFormatter = {
        let formatter = DateFormatter()
        formatter.locale = Locale(identifier: "en_US_POSIX")
        formatter.timeZone = CalendarDateKey.vietnamTimeZone
        formatter.dateFormat = "yyyy-MM-dd'T'HH:mm:ssXXX"
        return formatter
    }()
}

private enum GoogleCalendarError: LocalizedError {
    case invalidURL
    case invalidResponse
    case api(status: Int, detail: String)

    var errorDescription: String? {
        switch self {
        case .invalidURL:
            return "Địa chỉ yêu cầu không hợp lệ."
        case .invalidResponse:
            return "Google Calendar trả về dữ liệu không hợp lệ."
        case let .api(status, detail):
            return "Lỗi Google Calendar (\(status)): \(detail)"
        }
    }

private extension GoogleCalendarEvent {
    init?(payload: GoogleEventPayload) {
        guard let id = payload.id, payload.status != "cancelled" else { return nil }
        let title = payload.summary?.trimmingCharacters(in: .whitespacesAndNewlines)
        guard let startValue = payload.start, let endValue = payload.end else { return nil }

        if let startDate = startValue.date, let endDate = endValue.date,
           let firstDay = CalendarDateKey.date(from: startDate),
           let endExclusive = CalendarDateKey.date(from: endDate),
           let lastDay = CalendarDateKey.calendar.date(byAdding: .day, value: -1, to: endExclusive) {
            self.init(
                id: id,
                title: title?.isEmpty == false ? title! : "Sự kiện",
                details: payload.description,
                location: payload.location,
                start: nil,
                end: nil,
                isAllDay: true,
                firstDateKey: CalendarDateKey.string(from: firstDay),
                lastDateKey: CalendarDateKey.string(from: lastDay)
            )
            return
        }

        guard let start = Self.parseDateTime(startValue.dateTime),
              let end = Self.parseDateTime(endValue.dateTime) else { return nil }
        let finalInstant = end.addingTimeInterval(-1)
        self.init(
            id: id,
            title: title?.isEmpty == false ? title! : "Sự kiện",
            details: payload.description,
            location: payload.location,
            start: start,
            end: end,
            isAllDay: false,
            firstDateKey: CalendarDateKey.string(from: start),
            lastDateKey: CalendarDateKey.string(from: finalInstant)
        )
    }

    static func parseDateTime(_ value: String?) -> Date? {
        guard let value else { return nil }
        let precise = ISO8601DateFormatter()
        precise.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
        if let result = precise.date(from: value) { return result }
        let standard = ISO8601DateFormatter()
        standard.formatOptions = [.withInternetDateTime]
        return standard.date(from: value)
    }
}

# Lịch Việt

Ứng dụng lịch iPhone kết hợp lịch dương và âm lịch Việt Nam, ghi chú theo ngày, nhắc việc và xem sự kiện Google Calendar.
Ứng dụng này thuộc repository `lich-Viet-ios`.

## Mở project

1. Mở `Calendar.xcodeproj` bằng Xcode.
2. Chọn scheme **Calendar** và một iPhone Simulator hoặc iPhone đã kết nối.
3. Nhấn **Run** để build và chạy ứng dụng.

App hiển thị trên iPhone với tên **Lịch Việt**. Tên scheme và project Xcode vẫn là `Calendar`.

## Google Calendar

Lưu ý: thêm cấu hình OAuth iOS trong Google Cloud Console trước khi bật đăng nhập Google. Đặt client ID và URL scheme tương ứng trong cấu hình build của Xcode. Không commit client secret, khóa riêng tư hoặc file chứng thực vào repository.

## Nền tảng

- SwiftUI
- iOS 16 trở lên
- Google Sign-In SDK for iOS
